# หารูรั่วในพอร์ต

เครื่องมือวิเคราะห์ประวัติการเทรด — บอกว่าการขาดทุนของคุณกระจุกอยู่ตรงไหน

เสียบไฟล์ประวัติการเทรดจาก MT4/MT5 แล้วดูว่าถ้าไม้ที่แย่ที่สุดไม่กี่ไม้ไม่เคยเกิดขึ้น พอร์ตจะหน้าตาเป็นยังไง
พร้อมแยกดูตามคู่เงิน ขนาดไม้ ชั่วโมง และวันในสัปดาห์

## รันในเครื่องตัวเอง

```
pip install -r requirements.txt
streamlit run app.py
```

## ข้อมูลของคุณ

ไฟล์ที่อัปโหลดถูกประมวลผลในหน่วยความจำเท่านั้น ไม่มีการบันทึกหรือส่งต่อไปที่ใด

## ข้อสงวน

เครื่องมือนี้วิเคราะห์เฉพาะการเทรดที่เกิดขึ้นไปแล้ว **ไม่ใช่คำแนะนำการลงทุน
ไม่ให้สัญญาณ และไม่รับประกันผลตอบแทนใดๆ** ข้อมูลตัวอย่างที่แสดงเป็นบัญชีเดโม
